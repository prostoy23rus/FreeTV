## 📖 О проекте

**FreeTV Player** — это универсальный медиаплеер для комфортного и стабильного просмотра прямого эфира телевидения. Плеер оптимизирован под каждую платформу индивидуально:

- 📺 **FreeTV TV (для Android TV и ТВ-приставок)** — специализированная версия для больших экранов (10-foot UI), с полноценной поддержкой пульта ДУ, голосовым поиском, защитой от обрезки краёв (Overscan Safe), автоповторами и интеграцией с Leanback.
- 📱 **FreeTV Mobile (для смартфонов)** — оптимизирован для сенсорного управления: вертикальный режим с EPG и списком каналов, а при повороте в горизонталь — 100% чистый видеопоток без лишних кнопок.
- 🪟 **FreeTV Windows Desktop** — настольная версия с аппаратным ускорением GPU, поддержкой PiP («картинка в картинке») и горячими клавишами.

В приложение уже встроен актуальный проверенный плейлист с **более чем 590 открытыми телеканалами**, структурированными по понятным тематическим категориям.

## 🌟 Ключевые возможности

- 📺 **590+ проверенных каналов**: Эфирные, Кино и Сериалы, Познавательные, Детские, Музыка, Новости, Спорт, Региональные и Релакс.
- 📅 **Интерактивная телепрограмма (EPG)**:
  - Название текущей передачи и тайминг эфира.
  - Динамическая шкала прогресса (процент прошедшего времени передачи).
  - Подробное описание передачи и анонс следующей программы в эфире.
- ⚡ **Высокопроизводительный движок воспроизведения**:
  - Мгновенный запуск потоков HLS (`m3u8`), TS и MP4.
  - Аппаратное ускорение видеочипом устройства (GPU / MediaCodec).
  - Интеллектуальные автоповторы подключения при сбоях сети с автопереходом на нативный декодер.
- 🗂️ **Категории и фильтрация**:
  - Быстрое переключение между категориями (на ТВ — в удобном модальном окне по кнопке `OK`).
  - Поиск каналов с поддержкой системного голосового ввода Android TV.
  - ⭐ **Избранное**: сохранение и удаление любимых телеканалов прямо из списка.
  - 🕒 **История**: автоматическое сохранение последних воспроизведенных каналов.
- ✨ **Стартовый экран (Splash Screen)**:
  - Фирменный анимированный логотип FreeTV PRO со светящейся индикацией и прогресс-баром при запуске.
  - Плавное растворение заставки после готовности плейлиста.

## 📺 Версия для Android TV и ТВ-приставок (FreeTV TV)

- 🎮 **Свободная 2D-навигация с пульта ДУ**:
  - `Стрелки вверх/вниз/влево/вправо`: свободное перемещение между всеми элементами интерфейса с яркой неоновой подсветкой фокуса.
  - `OK` / `Enter`: запуск канала, открытие категорий, подтверждение действий.
  - `Стрелка вправо ►`: мгновенный переход на звёздочку «В избранное» у выбранного канала.
  - `Кнопка 0` (или `F`): моментальное добавление/удаление канала из избранного.
  - `CH+` / `CH-` (или `Page Up` / `Page Down`): быстрое переключение каналов во время эфира.
- ↩️ **Умная кнопка «Назад»**:
  - В полноэкранном режиме: возврат в стандартный режим с меню.
  - В списке каналов: мгновенный возврат к выбору категорий из любого места списка (не нужно листать сотни каналов обратно вверх).
  - При активном поиске: сброс строки поиска и возврат к полному списку.
  - На главном экране: подтверждение выхода из приложения.
- 🎙️ **Голосовой поиск каналов**:
  - По нажатию на строку поиска открывается нативный диалог Android TV с поддержкой микрофона на пульте.
  - Автоматический сброс поисковой строки при выходе из поиска.
- ⛶ **Полноэкранный режим по кнопке `[ ⛶ Во весь ]`**:
  - Полное скрытие боковой панели и интерфейса для чистого погружения в просмотр.
- 🛡️ **Защита от обрезки краёв экрана (TV Overscan Safe)**:
  - Изображение и логотипы каналов в углах больше не обрезаются физической рамкой телевизора.
- 📐 **Быстрое переключение формата экрана прямо во время эфира**:
  - Стрелками `◄` / `►` на пульте в полноэкранном режиме или кнопкой `[ 📺 Формат ]`:
    - **«Рамки» (Overscan Safe)** — безопасная зона под экран любого ТВ (по умолчанию).
    - **«Вписать» (Contain)** — 100% оригинальные пропорции без обрезки.
    - **«Без полос» (Cover)** — полное заполнение без черных полей.
    - **«16:9» (Fill)** — классическое растягивание.
  - Выбранный формат сохраняется автоматически.
- 🔄 **Автоматическое восстановление потока**:
  - Убрана неактивная кнопка повтора — плеер делает до 4 автоматических попыток переподключения при разрывах связи.
  - Окно ошибки мгновенно исчезает с экрана при начале реального воспроизведения видео.
- 🖼️ **Leanback Launcher**: официальный баннер для запуска с главного экрана Android TV.

## 📱 Оптимизация для смартфонов (FreeTV Mobile)

- 🔄 **Умная ориентация экрана**:
  - **Вертикальное положение (портрет)**: видеоплеер 16:9 сверху, инфо-панель текущего эфира, шкала телепрограммы EPG и удобный прокручиваемый список каналов внизу.
  - **Горизонтальное положение (ландшафт)**: чистый видеопоток на 100% экрана смартфона. Все панели управления скрываются, чтобы не мешать просмотру.
- 🪟 **Безрамочный режим (Display Cutout)**: изображение адаптируется под экраны с «чёлками» и вырезами для камеры без чёрных полос по бокам.
- 🔍 **Двойной тап**: быстрое переключение масштаба видео.
- 👆 **Сенсорные оптимизации**: крупные области нажатия на звездочку избранного (44×44 px), убраны лишние кнопки интерфейса.
- 🚪 **Удобный выход**: закрытие приложения по двойному нажатию кнопки «Назад» с системным уведомлением.

## 🪟 Возможности для Windows Desktop

- 🗔 **Режим «Картинка в картинке» (PiP)**: смотрите любимую передачу поверх всех окон во время работы за компьютером.
- 🖥️ **Полноэкранный режим**: разворачивание по нажатию клавиши `F` или двойному клику.
- 🛡️ **Обход сетевых ограничений**: встроенная эмуляция заголовков User-Agent и Referer для стабильного воспроизведения защищённых стримов.

## 🚀 Установка

### 📺 Android TV и ТВ-боксы:
1. Скачайте **[FreeTV.Android.TV.1.0.0.apk](https://github.com/prostoy23rus/FreeTV/releases/download/v1.0.0/FreeTV.Android.TV.1.0.0.apk)**.
2. Установите APK на телевизор (через флешку, приложение *Send Files to TV* или через *ADB*).
3. Приложение появится на главном экране в ленте Android TV / Google TV.

### 📱 Android (Смартфоны и планшеты):
1. Скачайте **[FreeTV.Android.Mobile.1.0.0.apk](https://github.com/prostoy23rus/FreeTV/releases/download/v1.0.0/FreeTV.Android.Mobile.1.0.0.apk)**.
2. Разрешите установку из неизвестных источников при запросе системы.
3. Откройте приложение — все каналы и телепрограмма готовы к просмотру.

### 🪟 Windows:
1. Скачайте **[FreeTV.Setup.1.0.0.exe](https://github.com/prostoy23rus/FreeTV/releases/download/v1.0.0/FreeTV.Setup.1.0.0.exe)**.
2. Запустите инсталлятор и завершите быструю установку.

## 💻 Сборка из исходного кода

### Android (Mobile & TV APK):
```bash
cd android
# Сборка версии для смартфонов
./gradlew assembleMobileDebug

# Сборка версии для Android TV
./gradlew assembleTvDebug
```

### Windows (Electron):
```bash
# Клонирование репозитория
git clone https://github.com/prostoy23rus/FreeTV.git
cd FreeTV

# Установка зависимостей и запуск
npm install
npm start

# Сборка Windows инсталлятора
npm run dist
```
