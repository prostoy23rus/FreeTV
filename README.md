## 📖 О проекте

**FreeTV Player** — это универсальный медиаплеер для комфортного просмотра прямого эфира телевидения. Приложение разработано для максимального удобства как на настольных ПК и ноутбуках, так и на мобильных устройствах и телевизорах под управлением Android TV.

В плеер уже предустановлен актуальный плейлист с **более чем 590 открытыми российскими телеканалами**, структурированными по понятным тематическим категориям.

---

## 🌟 Ключевые возможности

- 📺 **590+ проверенных каналов**: Эфирные, Кино и Сериалы, Познавательные, Детские, Музыка, Новости, Спорт, Региональные и Релакс.
- 📅 **Интерактивная телепрограмма (EPG)**:
  - Название текущей передачи и тайминг эфира.
  - Динамическая шкала прогресса (процент прошедшего времени передачи).
  - Подробное описание передачи и анонс следующей программы в эфире.
- ⚡ **Высокопроизводительный движок воспроизведения**:
  - Мгновенный запуск потоков HLS (`m3u8`), TS и MP4.
  - Аппаратное ускорение видеочипом устройства (GPU).
  - Автоматическое восстановление соединения при кратковременных сетевых сбоях.
- 🗂️ **Категории и фильтрация**:
  - Быстрое переключение между тематическими разделами.
  - Умный поиск каналов по названию и группе.
  - ⭐ **Избранное**: удобное сохранение любимых телеканалов прямо из списка.
  - 🕒 **История**: автоматическое запоминание последних воспроизведенных каналов.
- ⚙️ **Свои плейлисты**: возможность подключать внешние ссылки на любые M3U/M3U8 плейлисты через меню настроек.

## 📱 Оптимизация для смартфонов

- 🔄 **Автоматический поворот экрана**:
  - **В вертикальном положении (портрет)**: видеоплеер вверху (16:9), плашка телепрограммы под ним и удобный скроллинг каналов в нижней части экрана.
  - **В горизонтальном положении (ландшафт)**: чистый видеопоток на 100% экрана от края до края без элементов интерфейса.
- 🪟 **Поддержка безрамочных дисплеев**: поддержка режимов выреза экрана (`ShortEdges`) — изображение заполняет весь экран смартфона без чёрных полос вокруг селфи-камеры.
- 🔍 **Управление масштабированием**: двойной тап по видео в горизонтальном режиме переключает масштаб между оригинальными пропорциями (16:9) и полным заполнением экрана без полос.
- 👆 **Удобный тач-интерфейс**: крупные области нажатия (44×44 px) для звёздочки избранного.
- 🚪 **Чистый выход**: стандартный и удобный выход из приложения по двойному нажатию кнопки «Назад».

## 📺 Оптимизация для Android TV и ТВ-приставок

- 🎮 **Полноценная навигация с пульта ДУ**:
  - `Вверх` / `Вниз`: перемещение по списку каналов.
  - `OK` / `Enter`: переключение и выбор канала.
  - `CH+` / `CH-`: моментальное перелистывание каналов во время эфира.
  - `Цифры 0-9`: прямой быстрый ввод номера канала на пульте (например, наберите «1» для Первого канала или «42»).
  - `Назад`: выход из меню или завершение работы.
- 💡 **Специальная подсветка фокуса**: контрастное выделение активного элемента для комфортного управления на большом расстоянии от ТВ.
- 🖼️ **Leanback баннер**: приложение отображается на домашнем экране Android TV.

## 🪟 Возможности для Windows Desktop

- 🗔 **Режим «Картинка в картинке» (PiP)**: смотрите любимую передачу во время работы в других программах.
- 🖥️ **Полноэкранный режим**: разворачивание по нажатию клавиши `F` или двойному клику.
- 🛡️ **Обход сетевых ограничений**: встроенная эмуляция User-Agent для стабильного открытия региональных и защищенных IPTV-потоков.

## ⌨️ Горячие клавиши (Windows и пульт TV)

| Клавиша | Действие |
| :--- | :--- |
| `↑` / `↓` | Перемещение по списку каналов |
| `Enter` | Выбрать и включить канал |
| `Пробел` | Пауза / Возобновить воспроизведение |
| `F` | Полный экран (Fullscreen) |
| `0-9` | Прямой набор номера канала |
| `Escape` / `Назад` | Закрыть меню / Скрыть панель / Выход |

## 🚀 Установка

### Windows:
1. Скачайте **[FreeTV.Setup.1.0.0.exe](https://github.com/prostoy23rus/FreeTV/releases/download/v1.0.0/FreeTV.Setup.1.0.0.exe)**.
2. Запустите установщик и следуйте подсказкам мастера установки.
3. Ярлык плеера появится на рабочем столе и в меню «Пуск».

### Android (Смартфоны, планшеты и TV):
1. Скачайте **[FreeTV.Setup.Android.1.0.0.apk](https://github.com/prostoy23rus/FreeTV/releases/download/v1.0.0/FreeTV.Setup.Android.1.0.0.apk)**.
2. Откройте файл на устройстве и разрешите установку (при необходимости).
3. Приложение готово к работе без дополнительных настроек!

## 💻 Сборка из исходного кода

### Windows (Electron):
```bash
# Клонирование репозитория
git clone https://github.com/prostoy23rus/FreeTV.git
cd FreeTV

# Установка зависимостей
npm install

# Запуск приложения в dev-режиме
npm start

# Сборка готового инсталлятора Windows
npm run dist
```

### Android (APK):
```bash
cd android
./gradlew assembleDebug
# Готовый APK появится в android/app/build/outputs/apk/debug/
```
