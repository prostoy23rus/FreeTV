# FreeTV Player (Windows & Android)

Современный, высокоскоростной IPTV-плеер с открытым исходным кодом для **Windows**, **Android-смартфонов** и **Android TV / ТВ-приставок** с поддержкой HLS, встроенной программой передач (EPG) и каталогом 590+ открытых каналов.

---

## 🌟 Ключевые возможности

- 📺 **590+ качественных проверенных каналов** (федеральные, кино, спорт, познавательные, музыка, детские, радио).
- 📅 **Встроенная телепрограмма (EPG)** с отображением текущей и следующей передачи и таймлайном прогресса.
- ⚡ **Движок потокового воспроизведения HLS (m3u8), TS, MP4** на базе `hls.js` с аппаратным ускорением и минимальной задержкой.
- 🛡️ **Обход сетевых ограничений и эмуляция User-Agent** для стабильного открытия региональных и защищенных потоков.
- 🗂️ **Категории и группы**: мгновенное переключение между категориями.
- 🔍 **Умный поиск** по названиям каналов и группам на лету.
- ⭐ **Избранное**: сохранение любимых каналов с быстрым доступом.
- 🕒 **История просмотров**: автоматическое запоминание последних просмотренных каналов.
- 🗔 **Режим «Картинка в картинке» (PiP)** и полноценный полноэкранный режим (**F** / кнопка на панели).
- ⚙️ **Гибкая настройка источников**: поддержка добавления любых пользовательских M3U/M3U8 ссылок.

---

## 📺 Оптимизация под Android TV и ТВ-приставки
- 🕹️ **Полноценная навигация с пульта ДУ**:
  - `Вверх` / `Вниз`: переключение каналов.
  - `CH+` / `CH-`: моментальное переключение каналов.
  - `OK / Enter`: выбор канала / меню.
  - `Назад`: возврат или скрытие боковой панели.
  - `0-9`: прямой быстрый ввод номера канала на пульте.
- 🌟 **Специальная подсветка активного фокуса (D-Pad Focus)** для удобного управления на большом экране.
- 🖼️ **Leanback-лаунчер**: интеграция баннера приложения в главный экран Android TV.

---

## 📱 Оптимизация под смартфоны и планшеты
- 👆 **Сенсорный интерфейс**: крупные удобные элементы управления под палец.
- 🔄 **Адаптивный поворот экрана**:
  - В вертикальном режиме (портрет): видео сверху в формате 16:9, список каналов внизу.
  - В горизонтальном режиме (альбом): видео на весь экран с выезжающей шторкой каналов.

## 🚀 Установка и скачивание

Готовые сборки доступны в разделе **[Releases](https://github.com/prostoy23rus/FreeTV/releases)**:
- 🪟 **Для Windows**: скачайте `FreeTV Setup 1.0.0.exe` и запустите мастер установки.
- 🤖 **Для Android (Телефоны и ТВ)**: скачайте `FreeTV.Setup.Android.1.0.0.apk` и установите на устройство.

---

## 💻 Сборка из исходников

### Windows Desktop:
```bash
npm install
npm start        # Запуск в dev-режиме
npm run dist     # Сборка .exe установщика
```

### Android:
Откройте папку `android/` в Android Studio или соберите через Gradle:
```bash
cd android
./gradlew assembleRelease
```
